# Custom Vector Database Implementation

This repository contains a modular vector database built from scratch in Python. The system demonstrates how different indexing and search strategies handle vector similarity queries, utilizing local embeddings generated by Ollama.

## Supported Search Algorithms

This project implements three distinct indexing and search algorithms to demonstrate trade-offs in search speed and accuracy:

1. **Brute Force Index**: Calculates the Euclidean distance or Cosine Similarity from the query vector to every single document vector in the database, guaranteeing accurate results but scaling linearly in computational complexity $\mathcal{O}(N)$.
2. **KD-Tree (K-Dimensional Tree) Index**: A space-partitioning data structure for organizing points in a k-dimensional space. Great for lower-dimensional vector indexing $\mathcal{O}(\log N)$, but tends to degrade to near brute-force with highly dimensional embeddings.
3. **HNSW (Hierarchical Navigable Small World)**: A state-of-the-art approximate nearest neighbor (ANN) algorithm. It builds a hierarchical graph-based navigation structure that enables highly efficient large-scale and high-dimensional vector search.

## Prerequisites

You need to have [Ollama](https://ollama.com/) installed and running locally on your machine on port `11434`.

By default, this repository expects to cast embeddings using the `all-minilm` embedding model.

## Getting Started

1. **Start Ollama** (if running via command line):
   ```bash
   ollama serve
   ```

2. **Pull the necessary embedding model**:
   Before running the Python script, ensure you have specifically pulled the model to your local instance. Failure to download the model will result in an `HTTP Error 404: Not Found`.
   ```bash
   ollama pull all-minilm
   ```

3. **Execute the Database**:
   ```bash
   python main.py
   ```

### Note on Ollama API Endpoints
*Depending on the version of Ollama you have installed, the API structure may vary slightly.*

This codebase natively connects to the `http://localhost:11434/api/embed` endpoint, which is the current standardized embedding interface. Older tutorials and implementations may refer to the legacy endpoint (`/api/embeddings` payload: `prompt`). Be mindful of this when attempting to integrate Ollama with external integrations.
